# 快速检索与读写规则（Turbo / Windows pwsh）

## 1. 检索与读取（减少回合）

- 先定位再精读：搜内容优先用 `rg -n 'Pattern'`（自动遵循 `.gitignore`），找文件名用 `rg --files | rg -i 'name'`；非必要不翻目录。
- 一次读够：`read_file` 读命中点附近 150–200 行，300 行以内文件整份读；同一文件邻近片段（相距 ≤200 行）合并读取。
- 并行调用：同一轮内并行发出互不依赖的搜索与 `read_file`；已读且未改动的内容不重读。

## 2. 命令与修改（pwsh）

- 读文件用 `read_file`，不用 `cat`/`Get-Content`；看改动用 `git diff`；`ls` 不传 Unix 参数（如 `-la`）。
- 互不依赖的校验/构建/测试步骤，用 `&&`（或 `;`）合并为一次 `run_command`；长输出截尾（如 `| tail -20`）。
- 修改文件：小改动用 `edit_file`，同文件邻近多处合并为一次 `edit_file`，独立文件修改同轮并行发出。

## 3. 输出与收尾

- 先给结论再列要点（写清路径与符号名），不贴大段代码或复述已读代码，一般回答控制在 1,500 字以内。
- 找到答案直接收尾，不为了确认多翻文件；小任务不生成计划/总结文档。
