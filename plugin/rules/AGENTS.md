# 快速检索与读写规则（Turbo / Windows pwsh）

## 1. 检索与上下文控制（高优先级，覆盖内置并行预读策略）

- 窄搜精读，禁止地毯式预读：搜内容先用 `rg -l 'Pattern' .` 看命中分布，或直接用 `rg -n --max-columns 200 'Pattern' .` 锁定具体文件与行号（**必带路径 `.`，正则含 `$` 必用单引号**），再只读直接调用链或待改文件；**禁止**猜测性批量 `read_file`（未确认为目标的候选文件，单轮并行读取 **≤ 3 个**）。
- 摸清结构：未确认目录或文件名时先跑 `rg --files --iglob '*name*'` 或 `rg --files`，不盲猜子目录，非必要不 `ls` 翻目录。
- 大文件分段读：≤ 200 行的小文件可整份读；**行数未知或超过 200 行的文件必传 `StartLine`/`EndLine` 分段读取（禁止不传区间整文件读取）**，先用 `rg -n` 定位行号再按需读目标区间（单次 150–200 行一次读够，**上限 ≤ 200 行/次**；同文件邻近片段合并后总跨度 ≤ 200 行可一次读完）。
- 只读命令禁拼接：`rg`、`git status/diff/log/show` 等白名单只读命令**严禁**使用 `cd`、`&&`、`;`、`|` 或重定向拼接，必须单条独立并在同轮并行发出。
- 命令输出限流：白名单只读命令禁接管道，改用原生参数控量——`rg` 用 `-l`、`-m 20`、`--max-columns 200` 或限定路径/`--iglob`，`git diff` 先看 `--stat`/`--name-only` 再按路径 `git diff <path>`，`ls` 仅看单层具体目录，避免撞 `run_command` 10KB 截断或触发后台日志二次读取。
- 并行与去重：对已锁定行号的目标，同一轮内并行发出互不依赖的搜索与 `read_file`；已读且未改动的内容不重读。

## 2. 命令与修改（pwsh）

- 原生命令约束：读文件用 `read_file`，不用 `cat`/`Get-Content`；找文件用 `rg --files`，不用 `find`；看改动用 `git diff`；`ls` 不传 Unix 参数（如 `-la`），不用 `tail`/`head` 等非原生 Unix 命令。
- 必审命令合并与限流：互不依赖的校验/构建/测试等执行类步骤，用 `&&` 合并为一次 `run_command`；优先用工具自带精简参数控量（如 `-q`、`-n`），长输出加 `| Select-Object -First 60` 或 `-Last 20`。
- 修改文件：小改动用 `edit_file`，同文件邻近多处合并为一次，独立文件同轮并行；跨 ≥5 个文件的机械替换用单次脚本批处理后再 `git diff` 核对。

## 3. 输出与收尾

- 先给结论再列要点（写清路径与符号名），不贴大段代码或复述已读代码，一般回答控制在 1,500 字以内。
- 找到答案直接收尾，不为了确认多翻文件；小任务不生成计划/总结文档。
